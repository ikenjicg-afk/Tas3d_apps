# TAS3D apps

Сайт для зала форума TAS3D 2026. Сайт tas3d.uz здесь не используется. Всё на английском.

- `hi/` — гости (на эту страницу ведёт QR): отметка (роль + Confirm, один раз с телефона), потом пульт: Reactions (логотип TAS3D и 6 эмодзи) и анонимные Questions. Голосование, запущенное ведущим, всплывает у всех само.
- `host/` — ведущий, по паролю (ссылка Host внизу страницы гостя): сверху живая копия экрана; Check-in и Reset, Poll (готовые и свои; прошлые опросы с итогами остаются до Reset), Questions (Show on screen / Hide / Done), Game (игра открытия «Render TAS3D 2026»), Slides (папки спикеров: Start — экран на логотип и управление спикеру, Stop — логотип и управление хосту; показ и листание).
- `speakers/` — спикеры: сканируют QR-код из панели хоста (вкладка Slides) — входят без пароля; или пароль спикеров: выбирают свою папку и листают её у себя; после Start от хоста выводят на экран, листают ← →, запускают видео.
- Вход хоста запоминается на устройстве на 90 дней; Log out — двойным нажатием. В панели видно, работает ли экран (Screen: on/off).
- `screen/` — проектор, без пароля (ключ к презентациям приходит со ссылкой из панели хоста или из файла TAS3D Screen.html, либо пароль вводится один раз в Settings). Что на нём, решает ведущий в панели (блок On the screen): Blank, Logo, QR code, Check-in, Poll или Slides; QR вкл/выкл; реакции вкл/выкл. Вопрос — по центру. Сверху только Full screen (F); справа внизу Settings: папка презентаций (перетащить), звук видео, связь. → ← Page Down / Page Up (и кликер) — слайды.
- Презентации: на компьютере у проектора Settings → перетащить папку «TAS3D 2026 Presentations», в ней папка на каждого спикера. Показываются PDF, картинки и видео (MP4), по порядку имён файлов; PowerPoint и Keynote — сохранить как PDF. Файлы никуда не загружаются; пультам уходят только маленькие превью и команды, зашифрованные ключом от пароля (AES-GCM). Chrome и Edge запоминают папку и сами видят новые файлы.
- `assets/` — общие файлы (шрифты, логотип, QR, скрипты, pdf.js 6.2.108 — лицензия Apache 2.0 в `assets/pdfjs-6.2.108/LICENSE`); в адресе `?v=...`, чтобы после обновления браузер брал новую версию.

Как работает: сообщения идут через бесплатный публичный MQTT-сервер EMQX (`broker.emqx.io`, запасной `broker-cn.emqx.io`), тема `testtopic/tas3d2026/24s57u4s6z/...`. Аккаунт и ключи не нужны. Хранятся только роли, голоса и анонимные вопросы.
Пароли в коде не хранятся: только хеш (PBKDF2) и зашифрованный ключ для слайдов.

Сервер EMQX в двух адресах: телефон держит одно соединение и отправляет через него, копию — через второй адрес. Исходники и сборка: `tools/build_checkin.py` в рабочей папке сайта (папка `checkin/site`).

Данные до Reset: отметки, вопросы, голоса и итоги всех опросов хранятся и у хоста, и на экране; каждые 5 минут и после переподключения
они сверяются с серверами, и то, что сервер потерял, возвращается. Стирает всё только Reset.

Игра открытия: Game → Show the game (на экране фото в шуме рендера, у гостей кнопка RENDER) → Start rendering (3, 2, 1) →
все жмут; картинка открывается из черноты маленькими бакетами, как в V-Ray; на 100% — вспышка, наезд камеры, блик по логотипу, «TAS3D 2026 is open» и какая команда (роль) нарендерила больше. Считает экран. Пока игра на экране, переключение экрана из панели спрашивает подтверждение.

Звук: папка «Sound» внутри «TAS3D 2026 Presentations» подхватывается сама (или перетащить «Sound» в Settings на компьютере у проектора): первые 6 треков по имени — кнопки Track 1–6 во вкладке Sound
(выход спикера, переходы); папка «Music» внутри — музыка (кофе-брейк): хост выбирает трек из списка, дальше играет следующий;
Play/Pause, Next, громкость треков и музыки. Пока играет трек, музыка тише. Команды звука — только от хоста, зашифрованы.
