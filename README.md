# TAS3D apps

Сайт для зала форума TAS3D 2026. Сайт tas3d.uz здесь не используется. Всё на английском.

- `hi/` — гости (на эту страницу ведёт QR): отметка (роль + Confirm, один раз с телефона), потом пульт: Reactions (логотип TAS3D и 6 эмодзи) и анонимные Questions. Голосование, запущенное ведущим, всплывает у всех само.
- `host/` — ведущий, по паролю (ссылка Host внизу страницы гостя): Check-in и Reset, Poll (готовые и свои), Questions (Show on screen / Hide / Done), Slides (папки спикеров, показ, листание, «спикерам можно / нельзя выводить»), кнопка Screen.
- `speakers/` — спикеры, по паролю спикеров (ссылка Speakers внизу страницы гостя): выбирают свою папку, выводят её на экран, листают ← →, запускают видео.
- Вход хоста запоминается на устройстве на 90 дней; Log out — двойным нажатием. В панели видно, работает ли экран (Screen: on/off).
- `screen/` — проектор, тот же пароль. Что на нём, решает ведущий в панели (блок On the screen): Blank, Logo, QR code, Check-in, Poll или Slides; QR вкл/выкл; реакции вкл/выкл. Вопрос — по центру. Клавиша F — во весь экран; → ← Page Down / Page Up (и кликер) — слайды.
- Презентации: на компьютере у проектора кнопка Connect folder (появляется при движении мыши) → папка «TAS3D 2026 Presentations», в ней папка на каждого спикера. Показываются PDF, картинки и видео (MP4), по порядку имён файлов; PowerPoint и Keynote — сохранить как PDF. Файлы никуда не загружаются; пультам уходят только маленькие превью и команды, зашифрованные ключом от пароля (AES-GCM). Chrome и Edge запоминают папку и сами видят новые файлы.
- `assets/` — общие файлы (шрифты, логотип, QR, скрипты, pdf.js 6.2.108 — лицензия Apache 2.0 в `assets/pdfjs-6.2.108/LICENSE`); в адресе `?v=...`, чтобы после обновления браузер брал новую версию.

Как работает: сообщения идут через бесплатный публичный MQTT-сервер EMQX (`broker.emqx.io`, запасной `broker-cn.emqx.io`), тема `testtopic/tas3d2026/24s57u4s6z/...`. Аккаунт и ключи не нужны. Хранятся только роли, голоса и анонимные вопросы.
Пароли в коде не хранятся: только хеш (PBKDF2) и зашифрованный ключ для слайдов.

Сервер EMQX в двух адресах: телефон держит одно соединение и отправляет через него, копию — через второй адрес. Исходники и сборка: `tools/build_checkin.py` в рабочей папке сайта (папка `checkin/site`).
