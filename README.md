# TAS3D apps

Отдельные мини-приложения для форума TAS3D 2026. Сайт tas3d.uz здесь не используется.

## Отметка по QR (`hi/`)

- Адрес для телефонов: https://ikenjicg-afk.github.io/Tas3d_apps/hi/ (на него ведёт QR-код).
- Всё на английском. Гость выбирает роль (Visualiser, Architect, Developer, Student, Teacher, Other) и нажимает Confirm. Имя не нужно, один ответ с одного телефона.
- Reset на экране начинает новый раунд: экран и число на телефонах считают с нуля, телефоны снова показывают кнопки.
- Экран статистики — отдельный файл `TAS3D-ekran.html` на компьютере организатора, его не выкладывают.
- Отметки идут через бесплатный публичный MQTT-сервер EMQX (`broker.emqx.io`, запасной `broker-cn.emqx.io`), тема `testtopic/tas3d2026/24s57u4s6z/...`. Аккаунт и ключи не нужны. Хранятся только роли, имён нет.
- `hi/index.html` — один самостоятельный файл: шрифты, логотип и скрипты внутри.
