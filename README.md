# TAS3D apps

Сайт для зала форума TAS3D 2026. Сайт tas3d.uz здесь не используется. Всё на английском.

- `hi/` — гости (на эту страницу ведёт QR): отметка (роль + Confirm, один раз с телефона), потом пульт: Reactions и анонимные Questions. Голосование, запущенное ведущим, всплывает у всех само.
- `host/` — ведущий, по паролю (ссылка Host внизу страницы гостя): Check-in и Reset, Poll (готовые и свои), Questions (Show on screen / Hide / Done), счётчик реакций, кнопка Screen.
- `screen/` — проектор, тот же пароль: QR и отметки, во время голосования его результаты, выбранный вопрос, летящие реакции. Клавиши: Q — QR, F — во весь экран.

Как работает: сообщения идут через бесплатный публичный MQTT-сервер EMQX (`broker.emqx.io`, запасной `broker-cn.emqx.io`), тема `testtopic/tas3d2026/24s57u4s6z/...`. Аккаунт и ключи не нужны. Хранятся только роли, голоса и анонимные вопросы.
Пароль хранится только как хеш (PBKDF2): он не пускает гостей в панель, но это не серьёзная защита.

Каждый файл самостоятельный (шрифты и скрипты внутри). Исходники и сборка: `tools/build_checkin.py` в рабочей папке сайта.
